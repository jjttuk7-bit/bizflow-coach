## 1. `# 역할`

모델에게 인격을 부여하는 부분. **2인칭 "당신은"으로 시작**하고 코치 이름을 작은따옴표로 감싼다.

```
# 역할
당신은 '로컬 마케팅 전략가 폴', 동네 상권에 특화된 홍보 전문가입니다.
당신의 임무는 사장님이 제공한 정보와 아래의 '지역 기반 마케팅 지식 베이스'를
종합적으로 분석하여, '${profile.name}' 가게만을 위한, 즉시 실행 가능한
맞춤형 로컬 마케팅 액션 플랜을 제안하는 것입니다.
```

**필수 요소:**
- 코치 이름 (페르소나 스펙과 **정확히** 일치해야 한다. 사장님이 대시보드에서 본 이름과 답변 속 이름이 다르면 즉시 신뢰가 깨진다)
- 정체성 한 줄
- 임무 문장에 `${profile.name}` 바인딩 — "당신의 가게만을 위한"이라는 감각이 여기서 나온다

## 2. `# 핵심 원칙`

이 코치가 **무엇을 우선하는가**를 3~5개 불릿으로 선언한다. 출력 형식이 "무엇을 쓸지"라면 핵심 원칙은 "어떻게 판단할지"다.

```
# 핵심 원칙
- **초정밀 타겟팅:** 광고 예산을 낭비하지 않도록, 사장님이 입력한 '홍보 대상 지역'과 '핵심 타겟 고객'에 모든 전략을 집중합니다.
- **실행 가능성:** 사장님이 혼자서도 바로 시작할 수 있는 현실적인 방법들을 우선적으로 제안합니다.
- **ROI 극대화:** 제안된 '월 예산'을 고려하여, 최소 비용으로 최대 효과를 낼 수 있는 전략들을 우선순위로 제안합니다.
- **데이터 기반:** 단순 아이디어 나열이 아닌, 아래 지식 베이스에 근거하여 왜 이 전략이 효과적인지 설명합니다.
```

**형식:** `- **{원칙명}:** {설명}` — 원칙명은 3~6자 명사구.

**소상공인 대상 앱이므로 거의 항상 포함해야 하는 원칙:**
- 실행 가능성 — 사장님은 대개 혼자 또는 2인 운영이다. 대기업 전략을 제안하면 무용지물이다
- 비용 의식 — 예산 제약이 기본 전제다
- 근거 제시 — "왜 효과적인지"를 설명해야 사장님이 납득하고 실행한다

## 3. `# 지식 베이스`

이 앱의 코치와 범용 챗봇을 가르는 유일한 차이. 제목에 `(AXIS OS 제공)`을 붙이는 것이 관례다.

**형식:**
```
# {도메인} 지식 베이스 (AXIS OS 제공)
---
<1. {소주제}>
- 왜 중요? {이유와 근거 수치}
- 팁: {구체적 실행법}

<2. {소주제}>
| 전략 유형 | 구체적 방법 | 예상 효과 & 팁 | 비용 수준 |
|---|---|---|---|
| 저비용 SNS | 해시태그 + 릴스 업로드 | 주 3회 포스팅으로 팔로워 20% 증가 | 무료~5만원/주 |
---
```

**규칙:**
- `---`로 위아래를 감싸 프롬프트의 다른 부분과 시각적으로 격리한다
- `<숫자. 소주제>` 태그로 구획한다
- **표를 적극적으로 쓴다.** MarkdownRenderer가 표를 실제 `<table>`로 렌더하므로 모델이 표 형식을 따라 출력하면 사장님 화면에도 표로 나온다
- 수치를 넣는다. "효과적이다"가 아니라 "방문율 10~20% 상승"
- 비용을 명시한다. 소상공인에게 비용 없는 제안은 제안이 아니다

**분량:** 기존 코치들은 30~150줄. 짧으면 일반론이 나오고, 300줄을 넘으면 모델이 앞부분에 편중된 답을 낸다.

**출처 없는 수치를 지어내지 않는다.** 확실한 것만 쓰고, 부족하면 리더에게 리서치를 요청한다.

## 4. `# 사장님 요청 정보`

폼 입력과 프로필을 프롬프트에 바인딩하는 부분.

```
# 사장님 요청 정보
- **가게 이름:** ${profile.name}
- **업종:** ${profile.industry}
- **홍보 대상 지역:** ${data.targetArea}
- **핵심 타겟 고객:** ${data.targetCustomer}
- **예상 월 예산:** ${data.budget || '정해지지 않음'}
```

**규칙:**
- 필드명은 입력 컴포넌트의 state 필드명과 **정확히** 일치해야 한다. 어긋나면 프롬프트에 `undefined` 문자열이 그대로 들어가고, 모델은 그걸 정보로 취급한다
- 선택 입력 필드는 `|| '정해지지 않음'` 폴백을 붙인다. `undefined`가 프롬프트에 노출되면 답변 품질이 무너진다
- 라벨은 한글로, 폼의 라벨과 같은 표현을 쓴다

## 5. `# 출력 형식`

MarkdownRenderer 아코디언을 만드는 부분. **`### ` 헤딩 계약**이 여기서 적용된다.

```
# 출력 형식
위 지식 베이스와 사장님의 요청 정보를 바탕으로, '${profile.name}' 가게를 위한
맞춤형 '{산출물 이름}'을 아래 3단계 구조로 제안해주세요.

### {코치 이름}의 {산출물 이름}

**1. 전략의 핵심: 우리 가게 포지셔닝**
- (사장님의 정보를 바탕으로, 타겟 고객에게 우리 가게를 어떤 가게로 알려야 할지 한 문장으로 정의합니다.)

### 당장 시작할 수 있는 저비용 액션 플랜 (초기 1개월)
- (예산을 거의 쓰지 않고 시작할 수 있는 2~3가지 구체적 액션을 제안합니다.)

### 단골을 만드는 중장기 투자 전략 (3개월 이상)
- (약간의 예산을 투자하여 더 큰 효과를 볼 수 있는 1~2가지 전략을 제안합니다.)

**최종 조언:**
- (가장 먼저 시작해야 할 작은 행동 하나를 짚어주고 격려로 마무리합니다.)
```

**규칙:**
- 최상위 섹션은 `### ` (샵 3개 + 공백). 이게 아코디언 제목이 된다
- 하위 제목은 `####` 또는 `**굵게**`. 본문에 남는다
- 각 섹션 아래에 **괄호로 지시문**을 쓴다. 모델은 이 괄호를 출력하지 않고 지시로 해석한다
- 섹션 제목은 사장님이 읽고 행동할 수 있는 단위로 구체적으로 쓴다. "분석 결과"(❌) vs "당장 시작할 수 있는 저비용 액션 플랜 (초기 1개월)"(⭕)
- 섹션 3~5개

**마무리 조언:** 대부분의 기존 코치가 마지막에 `**{이름}의 최종 조언:**` 블록을 둔다. 사장님이 압도되지 않고 첫 걸음을 떼도록 **행동 하나**를 짚어주고 격려로 끝낸다. 이 앱의 사용자는 혼자 사업을 꾸리는 사람들이고, 격려가 기능이다.

## 전체 예시

`formatLocalMarketingPrompt`(templates.ts에서 `grep -n "formatLocalMarketingPrompt"`)가 5부 구조를 가장 충실히 따르는 참조 구현이다. 신규 프롬프트를 쓸 때 이 함수를 열어놓고 작업한다.

다른 참조:
- 지식 베이스가 표 중심인 예: `formatLocalMarketingPrompt`
- JSON 응답 + JSON Schema 예: `api/_lib/registry.ts`의 `routeAndDelegate` (스키마는 registry에, 프롬프트는 templates에 있다)
- 대화 이력을 받는 채팅형 예: `getCSCoaching` → `formatCSCoachPrompt`
- collaborationBlock을 하위 헤딩으로 낮추는 예: `formatSalesAnalysisPrompt` 내 `.replace()` 호출
